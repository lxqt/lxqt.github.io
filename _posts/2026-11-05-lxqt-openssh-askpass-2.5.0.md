The LXQt team announces the release of lxqt-openssh-askpass 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-openssh-askpass/releases).

Main changes:

 * Supported OpenSSH askpass prompt modes.
 * Update manual page.
 * CMake maintenance.
 * Updated the address of Free Software Foundation.

A full list of changes is in the CHANGELOG file.
