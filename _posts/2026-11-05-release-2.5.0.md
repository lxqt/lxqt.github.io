The LXQt team announces the release of **LXQt 2.5.0**, the Lightweight Qt Desktop Environment.

# Highlights

## General

 * The minimum required version of Qt is bumped to 6.10.0.
 * QTerminal and QTermWidget have received a lot of enhancements, including several new features (new background image modes, visual bell, OSC-8 hyperlink, silence notification, Shift+click selection, failed process communication, etc.) as well as bug-fixes.
 * LXQt does not depend on `menu-cache` anymore. It was the last LXDE dependency of LXQt. Now LXQt uses its own methods (in `libfm-qt`) to do the jobs of `menu-cache`, and it does them better and faster.
 * PCManFM-Qt's search has become incremental, such that the user can stop a heavy search, by clicking a button in the status-bar, while keeping the current results. Also, an option is added to Desktop Preferences for not using a wallpaper cache, such that the original image quality can be displayed.
 * Also, lots of CMake maintenance and code cleanup have been done. Although users do not notice them, they are crucial to a better code quality.

## LibFM-Qt / PCManFM-Qt

 * `menu-cache` is replaced by a built-in desktop-menu implementation.
 * The search is made incremental and a stop button is added to the status-bar. (Actually, LibFM-Qt supports incremental file listing now, but it is used only for searching because otherwise, it would take extra CPU time for no good reason.)
 * An option is added to Desktop Preferences for not using wallpaper cache.
 * A rare case of ghost items in the directory tree view is fixed.
 * The header of the detailed list view is made unmovable.
 * Cleanup and other small fixes.

## QTerminal and QTermWidget

In addition to several fixes,

 * New background image modes are added.
 * Optional visual bell is implemented.
 * Shift+click is supported for selecting a range.
 * An action is added for maximizing the current sub-terminal.
 * An option is added for notifying the user when the output stops inside a minimized window ("silence notification").
 * Options are added for OSC-8 hyperlinks.
 * Ending of a failed process is communicated by warning the user and allowing to save the history.
 * The D-Bus support is enhanced considerably.
 * And more …

## LXQt Panel

 * Network Monitor Plugin now respects lxqt-panel's icon size and can prefer system icons.
 * An option for the minimum width is added to Custom Command plugin.
 * The current brightness is shown in the tooltip of the backlight plugin.
 * Made the D-Bus task command work with auto-hiding panels.
 * Made the Close button the default button for config dialogs of relevant plugins.

And several other fixes and enhancements.

## LibLXQt

Reading of brightness is fixed with AMD GPU.

The LXQt team announces the release of **LXQt 2.4.0**, the Lightweight and modular Qt Desktop Environment.

# Highlights

## General

LXQt 2.4.0 brings mostly bugfixes and code cleanup but also some more nice improvements, while some new features and improvements were already included in the point releases of many components since November.

Required Qt versions have not changed, so building it on Debian "Trixie" and derivatives is still possible.

## LibFM-Qt / PCManFM-Qt

 * The base name in "File name" in the save dialog is automatically highlighted now which allows
immediate renaming of the file.
 * On Wayland the visibility of the desktop items with multi-screen desktop is consistent now (different "Hide Desktop Items" setting per each monitor).

And other small fixes and enhancements.

## LXQt-Powermanagement

 * A separate monitor blanking timeout has been added both for AC and battery, some useless options
 got removed from the combo boxes and the UI got a better overall layout.

## LXQt Panel

 * The volume plugin has now a horizontal layout and can display all available sinks and the default sink
volume can be tuned easily with mouse wheel or touchpad scroll on the icon on the panel.
 * Also fixed random crashes when PulseAudio sink information changes and some other small fixes and enhancements.

 Changes included already in **2.3.3**:

 * Fixed too strict parsing of alternative icon themes with Qt6.11.
 * The filter in "Fancy menu" prioritizes now starting strings of titles, e.g. "fir" will show always "Firefox" as first match.
 * On Wayland shortcut selectors in panel menus are disabled and a tooltip about how to configure it is added.
 * Fixed an issue with auto-hiding on dragging windows over Task Manager and Show Desktop.

And some other small fixes and enhancements.

## LXQt Sessions

 * Settings for X11 and Wayland sessions have been separated. <br/>
 The latter is still only shown when `lxqt-wayland-session`
 is installed.
 * The mainmenu can be opened now on Wayland too by adding a shortcut for `lxqt-qdbus openmenu` in the compositor
 settings.

## LXQt Runner

 * The integrated calculator will start now also when a number is typed first, not only with the equal sign.

## Notifications

 * Transient notifications (e.g. titles of songs from players and similar) are not saved anymore when "Do not disturb" mode is active.

## QTerminal and QTermWidget

 * The custom tab name behaviour is improved.
 * A shortcut can be added for the lock button (keep open) of the dropdown mode.
 * Fixed creation of bookmarks file with new profile.
 * Added "Nord" theme,
 * Fixed disappearance of Open/Copy link actions (in context menu).
 * Fixed the URL pattern which made URLs links 404 with a closing bracket when opened.
 * Implemented highlighting of all matches when searching and improved the code of highlighting.

And several other code fixes and enhancements.

## xdg-desktop-portal-lxqt

 * An access portal has been added (org.freedesktop.impl.portal.Access).

## Furthermore

 * Added $XDG_STATE_HOME directory implementation.
 * Fixed NotShowIn=LXQt handling in .desktop files.
 * Support logout from SystemdProvider.
