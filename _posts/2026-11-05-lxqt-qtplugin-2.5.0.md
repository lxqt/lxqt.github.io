The LXQt team announces the release of lxqt-qtplugin 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-qtplugin/releases).

Changes:

  * Fixed a case where SVG tray icons would not appear if they did not belong to the icon theme (because `QIcon::availableSizes` is empty for them).

  
<br/>
A full list of changes is in the CHANGELOG file.
