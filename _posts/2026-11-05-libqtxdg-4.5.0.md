The LXQt team announces the release of libqtxdg 4.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/libqtxdg/releases).

Changes:

 * Don't show C2Y extensions warnings.
 * Updated the address of Free Software Foundation.
 * Dropped string macros.
 * Open files in URI format with DBus activated apps.
 * Removed old codes belonging to Qt < 6.8 after bumping the minimum Qt version to 6.10.
 * Dropped QVector.
 * Removed unneeded headers.



<br/>
A full list of changes is in the CHANGELOG file.
