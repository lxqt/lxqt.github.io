The LXQt team announces the release of libdbusmenu-lxqt 0.4.0.
The release can be downloaded from [Github](https://github.com/lxqt/libdbusmenu-lxqt/releases).

 * Removed testapp (it didn't even build since KDE4 went away).
 * Removed redundant Qt link libraries.
 * CMake maintenance.
 * Don't automatically convert ASCII strings.
 * Use LXQt Build Tools.
 * Removed "with doc" build option.
 * Some cleanup.

<br/>
A full list of changes is in the CHANGELOG file.
