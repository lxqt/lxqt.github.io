The LXQt team announces the release of pcmanfm-qt 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/pcmanfm-qt/releases).

Main changes:

 * Enhanced the search by adding a stop button to status-bar.
 * Incremental search is supported by adding an optional stop button to status-bar (disabled by default).
 * Added an option for no wallpaper cache.
 * CMake maintenance.
 * Code cleanup and update.

<br/>
A full list of changes is in the CHANGELOG file.
