The LXQt team announces the release of lxqt-globalkeys 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-globalkeys/releases).

Changes:

 * Used `std::pair` instead of `QPair`.
 * Used US English in a string.
 * Updated the address of Free Software Foundation.

A full list of changes is in the CHANGELOG file.
