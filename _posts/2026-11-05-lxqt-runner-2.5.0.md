The LXQt team announces the release of lxqt-runner 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-runner/releases).

Main changes:

 * Silenced layershell's warnings by updating its code.
 * CMake maintenance.
 * Fixed compilation without math support.
 * Updated the address of Free Software Foundation.

<br/>
A full list of changes is in the CHANGELOG file.
