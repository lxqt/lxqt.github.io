The LXQt team announces the release of lxqt-build-tools 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-build-tools/releases).

Changes:

 * Set the C standard to C99.
 * Improved desktop file translations handling.
 * Updated min versions and readme.
 * Used PROJECT_NAME instead of CMAKE_PROJECT_NAME for generated config files.
 * Removed `FindMenuCache.cmake`.


<br/>
A full list of changes is in the CHANGELOG file.
