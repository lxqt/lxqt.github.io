The LXQt team announces the release of lxqt-admin 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-admin/releases).

Main changes:

 * Removed old codes of Qt < 6.7.
 * CMake maintenance.
 * Dropped the QL1C macro.
 * Updated the address of Free Software Foundation.
 * Capitalization.

<br/>
A full list of changes is in the CHANGELOG file.
