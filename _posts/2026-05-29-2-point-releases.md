The LXQt team announces two point releases:

**lxqt-panel 2.4.1**

Changes:

 * Fixed bug with volume scrolling not respecting the configured steps.
 * Changed volume plugin configuration steps default value from 3 to 5.


<br/>
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-panel/releases).


 **lxqt-wayland-session 0.4.1**

 * Updated wiki link in niri configs.
 * Updated for labwc 0.10.0.
 * Migrated Hyprland config to lua for 0.55 and fixed an error with legacy config.
 * Bumped version in lxqt-sway.config and removed doubled keybind.
 * Added method to show `lxqt-clip` to lxqt-qdbus script.
 * Added powerkeys actions shortcuts for suspend and sleep (hibernate).


<br/>
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-wayland-session/releases).
