The LXQt team announces the release of lximage-qt 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lximage-qt/releases).

Main changes:

 * Put image name in title-bar (image path is already in status-bar).
 * Removed deprecated codes that were for Qt < 6.9.
 * Removed translations CMake artifact.
 * Updated the address of Free Software Foundation.

<br/>
A full list of changes is in the CHANGELOG file.
