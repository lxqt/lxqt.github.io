The LXQt team announces the release of lxqt-powermanagement 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-powermanagement/releases).

Main changes:

 * Disabled the battery settings with no battery.
 * CMake maintenance.
 * Updated the address of Free Software Foundation.

A full list of changes is in the CHANGELOG file.
