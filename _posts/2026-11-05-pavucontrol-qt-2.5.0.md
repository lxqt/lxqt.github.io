The LXQt team announces the release of pavucontrol-qt 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/pavucontrol-qt/releases).

Main changes:

 * Updated peak meter latency handling.
 * Implemented Bluetooth codec selection and UI integration.
 * Included pavucontrol header in `cardwidget.cc`.
 * Don't show C2Y extensions warnings.
 * CMake maintenance.
 * Updated the address of Free Software Foundation.

<br/>
A full list of changes is in the CHANGELOG file.
