The LXQt team announces the release of lxqt-themes 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-themes/releases).

Main changes:

 * Removed wallpaper symlink from Silver theme.
 * Removed top/bottom padding, margins and borders in volume popup.
 * Lowered excessive menu-item padding.
 * Fixed two typos.
 * Fixed inconsistent semicolons on last lines of QSS blocks.
 * Corrected spacing inconsistencies and semicolon duplicates in several themes.
 * Fixed taskbar group popup for small panels.
 * Fixed formatting issues in `lxqt-panel.qss`.
 * Added 'on' state styling to plugin-volume of Clearlooks and Ambiance.
 * Added some padding to Ambiance.
 * Improved the QCalendarWidget style of Graphite.
 * Updated the address of Free Software Foundation.

<br/>
A full list of changes is in the CHANGELOG file.
