The LXQt team announces the release of libfm-qt 2.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/libfm-qt/releases).

Main changes:

 * Replaced menu-cache with a custom desktop-menu implementation.
 * Enhanced search experience by incremental file listing and being able to stop a search job.
 * Implemented incremental file listing (to be used by pcmanfm-qt only for searching).
 * Used `QPlatformFileDialogHelper::styleHint` instead of delayed showing of file dialog (the old workaround)
 * Fixed a regression in color and font dialogs.
 * Made tree view header unmovable.


<br/>
A full list of changes is in the CHANGELOG file.
