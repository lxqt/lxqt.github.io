The LXQt team announces the release of lxqt-archiver 1.5.0.
The release can be downloaded from [Github](https://github.com/lxqt/lxqt-archiver/releases).

Main changes:

 * Silenced some core C code warnings.
 * Removed nonexistent dir from the CMake Module paths.
 * Updated the address of Free Software Foundation.


<br/>
A full list of changes is in the CHANGELOG file.
