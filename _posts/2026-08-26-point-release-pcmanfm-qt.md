The LXQt team announces a point release of **pcmanfm-qt 2.4.1**


Changes:

 * Set desktop screen explicitly on Wayland.
 * Close tabs without close buttons by middle clicking with Qt ≥ 6.11.
 * Workaround for a bad behavior of wlroots.
 * Removed the redundant translations CMake file.
 * Set desktop file name.
 * Removed `<normaloff>` from ui files.
 * Updated FSF address in LICENSE.


<br/>
The release can be downloaded from [Github](https://github.com/lxqt/pcmanfm-qt/releases).
