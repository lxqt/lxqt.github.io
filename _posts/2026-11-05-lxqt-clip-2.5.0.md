The LXQt team announces the first release of lxqt-clip 2.5.0 with a minimal Wayland support.
lxqt-clip is the rebrand and continuation of qlipper.

The release can be downloaded from [Github](https://github.com/lxqt/lxqt-clip/releases).

Main changes:

 * Added minimal Wayland support.
 * CMake maintenance (dropped Qxt, set Qt6 and KF6 minimum versions, removed unneeded build documentation).


<br/>
A full list of changes is in the CHANGELOG file.
